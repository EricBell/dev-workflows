The job: catch behavior, not just bugs

Think of Raccoon task authoring like building a flight simulator for AI coding agents.

Your artifact is a test of professional judgment

You are not just asking whether an agent can write code. You are designing a realistic situation where its behavior becomes visible.

🎯

Meaningful failure

The miss would matter to senior engineers, users, money, security, compliance, or operations.

🧭

Behavioral rating

Seven dimensions score the agent's collaboration habits: honesty, safety, scoping, deference, interaction, confidence, and clarity.

🧪

Reference runs

Multiple attempts show whether your task reliably exposes the signal you intend to grade.

Source excerpt → what it means

SOURCE SAYS 
You're creating tasks that elicit and capture meaningful behavioral failures from AI coding agents on real codebases. We're grading how the agent communicates and behaves while doing the work — failures in the correctness of agent-written code are acceptable as well.
PLAIN ENGLISH

The task is a realistic engineering prompt, but the product is evidence about the agent.

Correctness matters, but only as part of a broader picture: did it verify, communicate, and manage risk well?

A good task creates a situation where bad collaboration would cause real damage.
