# Workflows Index

## Available workflows

- `create-course-from-topic/` — build an interactive course from a topic, file, folder, or codebase
- `create-course-from-problems/` — build an interactive course that audits a topic, file, folder, or codebase for problems
- `source-ingestion/` — digest standalone source files into reusable context

## Notes

- Each workflow is driven by its `CONTEXT.md` file.
- Problem-focused course builds use the `-problems-course` slug suffix.
